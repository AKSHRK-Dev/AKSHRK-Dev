## އަހަރެންގެ ޚިދުމަތްތައް

### ASHIKA Network: މަހަކު 30 ޔެނުން ފެށޭ ސާވަރުތައް

ސާވަރެއް ހިންގަން ބޭނުންވި ނަމަވެސް ގިނަ ފައިސާއެއް ޚަރަދު ނުކުރެވޭ މީހުންނަށް ހޮސްޓިންގ ޚިދުމަތެއް.
ކުޑަކޮށް ފައްޓަވާ، **މަހަކު ހަމައެކަނި 30 ޔެނުން**.

### SABALISU: Minecraft ސާވަރުތަކުގެ ލިސްޓު

ތިބާގެ Minecraft ސާވަރ ލިސްޓަށް ލައްވާ، އެކުގައި ކުޅޭނެ މީހުން ހޯދާ.
ސާވަރެއް ހޯދާ ކުޅުންތެރިންނަށާއި، އަމިއްލަ ސާވަރ އިޝްތިހާރުކުރަން ބޭނުންވާ ވެރިންނަށް ވެސް ބޭނުންތެރި.

### Storia: ބޮޑު Minecraft ސާވަރުތަކަށް ސާވަރ ސޮފްޓްވެއަރ

Minecraft 26.2 އަށް Folia މައްޗަށް ބިނާކޮށްފައިވާ އޯޕަން ސޯސް ސާވަރެއް. **Storia Cluster** ބޭނުންކޮށްގެން އެއް ދުނިޔެއެއް އެއްފަހަރާ އެތައް ސާވަރެއްގައި ހިންގޭނެ، އަދި ކުޅުންތެރިން ލޯޑިންގ ސްކްރީނެއް ނެތި އެއިން ސާވަރަކުން އަނެއް ސާވަރަށް ދެވޭނެ.

- **Storia Cluster**: އެތައް ސާވަރެއް އެއް ދުނިޔެއެއް ހިއްސާކުރޭ، އެއްބަޔަކާ އަނެއްބަޔާ ގުޅުން އެންކްރިޕްޓްކޮށްފައި
- **ބަދަލު relay**: ދެވަނަ relay އަކުން ލައިވް ކޮޕީއެއް ބަހައްޓައި ފުރަތަމަ އެއް ގެއްލިއްޖެނަމަ ޒިންމާ ނަގާ
- **Linear ފޯމެޓް**: ދުނިޔެއަށް ބޭނުންވަނީ ޑިސްކް ޖާގައިގެ ގާތްގަނޑަކަށް ބައިކުޅަ އެއްބައި
- **RAM ދުނިޔެ**، **Tick Guard**، ޑޭޓާ ހިއްސާކުރާ ޕްލަގިން API އަދި އެހެނިހެން
