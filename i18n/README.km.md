សេវាកម្មបង្ហោះសម្រាប់អ្នកដែលចង់ដំណើរការម៉ាស៊ីនមេ ប៉ុន្តែមិនអាចចំណាយច្រើន។
ចាប់ផ្ដើមតូចៗ **ត្រឹមតែ 30 យ៉េនក្នុងមួយខែ**។

### SABALISU៖ បញ្ជីម៉ាស៊ីនមេ Minecraft

ចុះបញ្ជីម៉ាស៊ីនមេ Minecraft របស់អ្នក ហើយស្វែងរកអ្នកលេងជាមួយ។
មានប្រយោជន៍ទាំងសម្រាប់អ្នកលេងដែលកំពុងរកម៉ាស៊ីនមេ និងម្ចាស់ដែលចង់ផ្សព្វផ្សាយម៉ាស៊ីនមេរបស់ខ្លួន។

### Storia៖ កម្មវិធីម៉ាស៊ីនមេសម្រាប់ម៉ាស៊ីនមេ Minecraft ធំៗ

ម៉ាស៊ីនមេប្រភពបើកចំហដែលបំបែកចេញពី Folia សម្រាប់ Minecraft 26.2។ ជាមួយ **Storia Cluster** ពិភពលោកមួយអាចដំណើរការលើម៉ាស៊ីនមេច្រើនក្នុងពេលតែមួយ ហើយអ្នកលេងផ្លាស់ទីរវាងពួកវាដោយគ្មានអេក្រង់ផ្ទុក។

- **Storia Cluster**៖ ពិភពលោកមួយចែករំលែកដោយម៉ាស៊ីនមេច្រើន ជាមួយការតភ្ជាប់ដែលបានអ៊ិនគ្រីប
- **Relay បម្រុង**៖ relay ទីពីររក្សាច្បាប់ចម្លងផ្ទាល់ ហើយជំនួសប្រសិនបើ relay ទីមួយបាត់បង់
- **ទម្រង់ Linear**៖ ពិភពលោកប្រើទំហំថាសប្រហែលពាក់កណ្ដាល
- **ពិភពលោកក្នុង RAM**, **Tick Guard**, API កម្មវិធីជំនួយសម្រាប់ចែករំលែកទិន្នន័យ និងច្រើនទៀត
