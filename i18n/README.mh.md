### Storia: software in server ñan Minecraft server ko reļļap

Juon open-source fork in Folia ñan Minecraft 26.2. Ippān **Storia Cluster**, juon lal emaroñ jerbal ilo elōñ server ilo ejja juon iien, im ri-kūrel ro rej ito-itak ikōtaan er ilọkin loading screen.

- **Storia Cluster**: juon lal elōñ server rej kōjerbale, im kōkkeitak ko ikōtaan er rej encrypted
- **Standby relay**: relay eo kein ka-ruo ej kōjparok juon kopi im ej bōk jikin eo kein ka-juon ñe ejako
- **Linear format**: lal ej kōjerbal jimettan in jikin ilo disk
- **RAM lal**, **Tick Guard**, juon plugin API ñan data ko rej kōjerbali ippān doon, im elōñ bar
