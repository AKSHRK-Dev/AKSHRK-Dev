### Storia: نرم‌افزار سرور برای سرورهای بزرگ Minecraft

یک سرور متن‌باز بر پایهٔ Folia برای Minecraft 26.2. با **Storia Cluster** یک جهان می‌تواند هم‌زمان روی چندین سرور اجرا شود و بازیکنان بدون صفحهٔ بارگذاری میان آن‌ها جابه‌جا می‌شوند.

- **Storia Cluster**: چندین سرور یک جهان را شریک می‌شوند و ارتباط میان آن‌ها رمزگذاری شده است
- **ریلهٔ ذخیره**: ریلهٔ دوم یک نسخهٔ زنده نگه می‌دارد و اگر اولی از دست برود، جای آن را می‌گیرد
- **قالب Linear**: جهان تقریباً نیمی از فضای دیسک را می‌گیرد
- **جهان RAM**، **Tick Guard**، API افزونه برای اشتراک داده و بیشتر
